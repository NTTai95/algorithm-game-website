# Change & Proposal System

This directory houses formal Architectural & Technical Proposals generated by AI agents.

## When a Proposal is Mandatory
Future AI agents MUST NOT unilaterally or silently implement changes when discovering:
1. **Architectural Incompatibilities**: Conflicts between planned designs and existing boundaries.
2. **Breaking API Changes**: Any alteration to established contracts in `.ai/API_CONTRACTS.md`.
3. **Cross-System Conflicts**: Inconsistencies between domain simulation requirements and renderer requirements.
4. **Dependency Modifications**: Needs for new external npm libraries or toolings.
5. **Major Refactoring**: Opportunities or needs to overhaul existing systems.
6. **Out-of-Scope Requirements**: Discoveries that extend beyond the boundaries of the currently claimed task.

## Proposal File Format
Create a markdown file: `PROP-XXX-<short-title>.md` containing:
- **Title & Author**: Proposing AI Agent ID and date.
- **Problem Statement**: What conflict or limitation was observed.
- **Proposed Solution**: Technical design, interfaces, or changes.
- **Impact Analysis**: Affected files, potential breaking points, or dependency requirements.
- **Status**: `PROPOSED` (awaiting human decision: `ACCEPTED` / `REJECTED`).
