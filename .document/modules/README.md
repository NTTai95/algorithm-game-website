# Danh Mục Đặc Tả Kỹ Thuật Các Module (.document/modules)

Thư mục này dành để lưu trữ các tài liệu đặc tả kỹ thuật chi tiết của từng module con trong dự án khi chúng được phát triển hoặc mở rộng.

---

## 1. Nguyên Tắc Quản Lý Đặc Tả Module

- Mỗi file đặc tả module được tạo từ mẫu [`.ai/templates/documentation/MODULE_SPEC_TEMPLATE.md`](file:///d:/workspace/Algorithm-game-website/.ai/templates/documentation/MODULE_SPEC_TEMPLATE.md).
- Đặt tên file theo định dạng: `MOD-[MÃ]-[tên-module].md` (ví dụ: `MOD-001-simulation-engine.md`).
- Chỉ tạo tài liệu chi tiết khi một module con đạt độ phức tạp đáng kể cần phân ranh giới rõ ràng.

---

## 2. Trạng Thái Hiện Tại

Trong giai đoạn khởi tạo nền tảng hiện nay, chưa có module con nào yêu cầu tài liệu đặc tả riêng biệt. Ranh giới kiến trúc cấp cao được định nghĩa tại [`.document/ARCHITECTURE.md`](file:///d:/workspace/Algorithm-game-website/.document/ARCHITECTURE.md) và cấu trúc thư mục được mô tả tại [`.document/SYSTEM_MAP.md`](file:///d:/workspace/Algorithm-game-website/.document/SYSTEM_MAP.md).
