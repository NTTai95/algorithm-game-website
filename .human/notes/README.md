# Ghi Chú Vận Hành Của Con Người (.human/notes)

Thư mục này dùng để lưu trữ các ghi chú kỹ thuật dùng chung, mẹo vận hành và thông tin tham khảo nội bộ giữa 2 lập trình viên con người.

---

## 1. Mục Đích Sử Dụng
- Lưu các ghi chú trao đổi giữa 2 lập trình viên con người.
- Lưu lại các đường dẫn hữu ích, tài liệu tham khảo bên ngoài.
- Lưu lại cấu hình môi trường chung không chứa thông tin bí mật.

---

## 2. Lưu Ý An Toàn
- Các tệp trong thư mục này được Git theo dõi để chia sẻ giữa 2 máy.
- **TUYỆT ĐỐI KHÔNG** lưu mật khẩu, API keys, access token hoặc thông tin nhạy cảm vào thư mục này.
